# 🎂 happy-birthday

[김성주의 생일 바탕화면](https://sjkim1127.github.io/happy-birthday/)입니다.

- 촛불을 모두 끄면 색종이가 터지고 생일 축하 노래가 나옵니다.
- 타이머는 2026년 11월 27일 0시(KST)에 생일 시작을 알리고, 당일에는 자정까지 남은 시간을 표시합니다.
- 설문에서 `늙었다`를 누르면 어두운 복도에서 토끼가 달려오고, `젊다`를 누르면 사랑 고백을 받습니다.
- 작업 표시줄과 시작 메뉴에서 창을 다시 열 수 있습니다. 넓은 화면에서는 제목 표시줄과 스티커를 끌어서 옮길 수 있습니다.

빌드 없이 `index.html`을 열면 사용할 수 있습니다. 문구는 `index.html`, 바탕화면 스타일은 `desktop.css`에서 바꿀 수 있습니다.

## 에셋

- 배경은 [Microsoft Design의 Microsoft Nostalgic Scenes](https://microsoft.design/wallpapers/)에 포함된 Bliss 리마스터입니다. 원본 `Microsoft_Nostalgic_Windows_Wallpaper_4k.jpg`를 두 가지 크기의 WebP로 변환했습니다.
- 아이콘은 [Microsoft Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) 1.1.347에서 가져왔습니다. [MIT 라이선스](assets/icons/LICENSE)를 함께 제공합니다.
- 토끼는 첨부 이미지를 참고해 제작한 투명 스프라이트입니다.
