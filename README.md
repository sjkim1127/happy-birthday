# 🎂 happy-birthday

생일 축하 페이지입니다: https://sjkim1127.github.io/happy-birthday/

레트로 Windows 감성의 생일 페이지입니다.

- 촛불을 눌러서 모두 끄면 색종이가 터지고 노래가 나옵니다.
- 생일 시작(11월 27일 0시 KST)까지 남은 시간을 보여주고, 생일 당일에는 끝날 때까지 남은 시간으로 바뀝니다.
- 지뢰찾기를 할 수 있고, 창과 스티커는 끌어서 옮길 수 있습니다.
- 설문에서 `늙었다`를 누르면 무서운 그림이 튀어나오고, `젊다`를 누르면 사랑 고백을 받습니다.
- 닫은 창은 `시작` 버튼으로 다시 엽니다.

문구는 `index.html`에서 바꿀 수 있습니다.
